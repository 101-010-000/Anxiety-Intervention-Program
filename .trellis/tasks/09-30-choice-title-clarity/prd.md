# 选择题题干标题清晰化（加底板+提字号+去材质覆盖）

## Goal

全 5 章共用的选择题面板（`ChoicePanel`），**题干标题**在游戏画面上看不清（用户 2026-09-30 试玩录屏反馈：「整个游戏里面的所有选择题的标题，感觉都不是很清晰」）。
所有章共用同一个 ChoicePanel → 修一处 = 全部选择题生效。

## 现状与根因（已核实，2026-09-30）

1. 题干 = `UI交互/ChoicePanel/Panel/Title`，uGUI Text，字体 中文_Deng（等线，笔画细），38 号 Bold，颜色 #CCE3FF（2026-10-01 配色工具已跑过）。
2. ★ **无底板**：面板背景透明，题干直接压在 ChoicePanel 自己的 Dim + 底层 68% 遮罩 + 场景画面上——场景的亮部和杂色直接干扰笔画。对照组：选项行有云朵气泡底图 + 白字，所以清晰。
3. ⚠ **材质覆盖隐患**：2026-10-01 配色报告明确标注 Title 的 Text 挂着「Default UI Material」材质覆盖，顶点色可能被材质压住——实际渲出的颜色从未验证过，可能比 #CCE3FF 更暗。

## Requirements

- R1 题干在任意地点、任意场景亮度（亮如白天宿舍、暗如走廊）的背景上都能一眼读清。
- R2 底板样式沿用现有 UI 词汇（选项行云朵气泡 / 左上目标卡玻璃卡的素材库贴图），不引入新风格。
- R3 题干保持「场景真实节点、用户可手调」；运行时不覆盖手调（沿用选项行的既有约定）。
- R4 一处修改覆盖全部选择题（共用面板，不按章复制节点）。
- R5 排除材质覆盖隐患：Title 的 material 覆盖清掉，回落字体默认材质。
- R6 幂等 Editor 工具落地 + 报告 + 预览图，遵循仓库触发器/报告约定。

## Constraints

- 不动选项行、确认按钮的样式（用户手调过云朵气泡，运行时/工具都不碰）。
- 不动「对话框/名字/对话内容」（2026-09-23 用户定稿铁律）。
- 字体仍用 中文_Deng（用户抱怨的是清晰度，不是字体）。
- 运行时 `ChoicePanel.cs` 零改动（Open() 只写题干文字，底板是纯场景改动）。

## Acceptance Criteria

- [ ] Play 进任意一章的选择题：题干有底板，在亮/暗两种场景背景上都清晰可读。
- [ ] 工具重跑幂等：已有底板不重复建、不覆盖用户手调的数值。
- [ ] 报告 `assets/_报告/_选择题题干清晰化.txt`：字号/颜色/底板贴图/材质覆盖检查结果。
- [ ] 预览图存 `assets/_报告/预览/场景/`（修后效果，可与用户录屏截图对照）。
- [ ] 选项行、确认按钮、对话框样式零变化（报告里写明未触碰）。

## 方案

详见 `design.md`。推荐 **方案 A：题干加「标题条」底板**（复用素材库 `面板_标题条.png`）+ 字号 38→44 + 描边/投影 + 清材质覆盖；备选 B 为纯文字加强（不加底板）。
