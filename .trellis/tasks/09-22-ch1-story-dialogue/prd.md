## Goal

在 Game.unity（Loc_教室 → Loc_走廊）中把《剧本.docx》第一章（119 个剧情步骤）跑成可玩的剧情演出：开场旁白自动播放但**不进对话模式**，玩家走到组长身边**按 F 交互**才触发对话；台词按**对话 / 旁白 / 心理独白**三语态呈现，复用已搭好的 `UI_门口交互/Dialog`（文本换回 uGUI Text）；单句播完的间隙可**转动视角但不能移动**；4 处干预选择题采用"任选一项 → 展开对应解释 → 强制选完剩余项"的全选流程；林溪微信段用**手机聊天 UI 模拟真实微信**（素材程序化占位）；每章结束返回主界面并显示固定提示句。

## Requirements

- **R1 三语态台词**：同一 Dialog 渲染三类，第一章全量录入（119 步）。分类规则：带【角色名】→对话；无【】第一人称口语→独白；无【】第三人称叙述→旁白。对话=名牌+常规白字；旁白=无名牌灰白；独白=无名牌浅色斜体。
- **R2 淡入淡出**：节点开始/结束框体淡入淡出；逐句旧句淡出→新句打字机；语态切换名牌/字色过渡；开场黑幕+章节卡；面板淡入淡出。
- **R3 控制权限状态机**：打字中=锁视角+锁移动；**间隙（该句打字机结束）=可转视角、不可移动**；走动段=恢复移动；面板/演出=全锁。开场旁白按台词规则（锁移动），旁白结束框体淡出、恢复移动并提示去交互。
- **R4 干预选择题全选流程**（4 处，文案照抄剧本）：点选任一项→该选项下方展开对应解释→标记已记录→剩余项继续可选→全部选过→"记入焦虑记录本"点亮→确认收档→回剧情。
- **R5 台词以剧本为主**：仅修 3 处明显笔误（"不自绝"→"不自觉"、"越在以结果"→"越在意结果"、题干"李同学"→"张同学"）。
- **R6 动线与触发**：章节卡→开场旁白（自动，不进对话模式）→**走到组长身边按 F 交互**进入对话（提示"按 F 与组长交谈"，交互一次后失效）→组长段+① →原地手机段（切入手机聊天 UI）→② →收书包**自由走到教室门口**、撞张知远（触发盒，一次）→张知远段+③④→走廊收尾。剧情期间门口传送系统抑制。
- **R7 Dialog 复用与补件（已同意）**：name/neirong 换 uGUI Text + 中文_Deng；补 CanvasGroup、▼指示、语态样式；布局按设计分辨率重排；DialogBack 换 Image+九宫格（保留聊天背景.png）。全部改动经 Editor 工具。
- **R8 手机微信聊天 UI（本期做，占位素材）**：切入后模拟真实微信——外框/状态栏/聊天头/气泡（林溪左白、徐夏右绿）/表情包占位/"正在输入…"；**视角切换至林溪 = 聊天头变"徐夏"、气泡左右镜像**；②面板浮于手机 UI 上，全选收档后**首个选中的选项作为林溪的消息气泡发出**（补完"而且——"）；结束手机 UI 淡出回 3D。素材程序化生成（MainMenuAssets 风格），真素材后补只换贴图。
- **R9 章节结尾（每章通用）**：章节卡"第一章 完"+副文固定提示句"查看本章核心内容...请前往填写实验者发的问卷链接~"→点击返回主界面。
- **R10 设置联动**：推进=左键/空格/回车（打字中点击=先补全）；打字速度、自动播放接 GameSettings。

## Acceptance Criteria

- [ ] Play 模式从第一章起点开始，119 步全部顺序演出，台词与剧本逐字一致（除 R5 三处笔误）。
- [ ] 开场旁白自动播放且不进入对话交互；结束后可自由移动，走到组长附近出现"按 F 与组长交谈"，按 F 才进入对话；重复按 F 不再触发。
- [ ] 三语态视觉可辨（对话名牌、独白浅色斜体、旁白灰白无名牌）。
- [ ] 单句打字机结束进入间隙：转视角有效、移动无效；推进进入下一句；对话节点结束移动恢复。
- [ ] 4 处干预面板：未全选不可关闭；每选一项展开对应解释；全选后收档并回剧情；②收档后聊天中出现首个选中项的消息气泡。
- [ ] 手机聊天 UI：气泡方向正确；切林溪视角后聊天头为"徐夏"且气泡镜像；"正在输入…"与表情包占位可见；素材为程序化占位。
- [ ] 中文在 name/neirong（uGUI Text+中文_Deng）清晰显示无模糊无方块。
- [ ] 淡入淡出按规范生效（框体/逐句/黑幕/章节卡/面板）。
- [ ] 撞张知远触发盒一次即消费；剧情期间门口传送提示不出现。
- [ ] 章节结束卡显示固定提示句，点击返回 MainMenu。
- [ ] Editor 工具（菜单+`_story1_trigger.txt`）幂等重建全部剧情 UI/触发/摆位，重跑无重复节点。
