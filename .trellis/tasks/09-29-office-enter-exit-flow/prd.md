# 第三章办公室进出流程改造（走廊方案，2026-09-29 用户定稿）

## Goal

第三章"进办公室"走**现成的 Loc_走廊**串场，不新建任何布景：

1. 食堂剧情完 → 玩家走到**食堂大门 `Door_G_Frame (1)`** 交互「去走廊」→ fade 到 **Loc_走廊**（缺省落在走廊现成的 `Door_B_Frame` 前，锚点可手挪）；
2. 玩家沿走廊走到**用户手摆的 `对象112`**（办公室门·走廊侧）交互「进入办公室」→ fade 进 Loc_办公室（`第3章_办公室内`）；
3. 办公室剧情照旧；
4. 出办公室 → 玩家走到 **Loc_办公室 下用户手摆的 `对象112`**（屋内侧）交互「离开办公室」→ fade 回 **Loc_走廊 的 `对象112`** 位置，继续出场剧情。

## 教训（为什么推翻方案A）

第一版自建了"门外走廊 4×4m + 门框墙 + 复制门扇"（`Shell_门外走廊` 等），用户否决：**有现成的走廊和手摆的门，不要自己搭**。方案A物件由工具自动撤销（删 `Shell_门外走廊`/`办公室门`/`门框墙_南门`，按改动前 dump 的精确 localPos/rot 恢复南墙板 `墙_0`，`第3章_办公室外` 锚点还原位）。
