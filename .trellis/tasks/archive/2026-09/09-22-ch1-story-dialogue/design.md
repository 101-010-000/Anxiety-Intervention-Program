## 2. 剧情数据格式（不变）

`{"steps":[{"t":"nar|dlg|mon|choice|cam|stick|walk|interact|card|end", "s":"说话人", "x":"文本", "options":[...]}, ...]}`。新增 `interact` = 等待玩家走到指定交互点按 F（携带交互点名与提示文案）；`cam` 语义细化为 `cam:phone_in`（切入手机 UI）/ `cam:phone_out`（淡出回 3D）。多章扩展 = 每章一个 json。

## 3. 开场流程与控制权限（v2 关键变更）

**开场**：LoadScene 后 → 黑幕淡入场景 + 章节卡"第一章"（S01）→ **开场旁白 S02–S09 自动连播**（台词规则：打字中锁全部、间隙可转视角；不进入对话交互，也无需按 F）→ 旁白完框体淡出、恢复移动 + HUD 提示"走到组长身边，按 F 交谈" → `interact` 步骤等待 → 玩家走近组长（半径约 2m 触发盒显示"按 F 与组长交谈"，样式复用门口系统的提示）→ 按 F → 进入对话模式 S11 起正式演出。

| 状态 | 视角 | 移动 | 光标 | 进入条件 |
|---|---|---|---|---|
| 打字机播放中 | 锁 | 锁 | 锁定 | 每句开始 |
| **间隙（一句说完）** | **可转** | **锁** | 锁定 | 打字机结束（="说完话"判定） |
| 走动段（walk） | 可转 | **可动** | 锁定 | 对话节点结束 |

| 手机聊天 UI | 锁 | 锁 | 锁定（点左键/空格推进） | cam:phone_in |
| 干预面板 | 锁 | 锁 | 解锁可点 | choice 步骤 |
| card / end / cam 过场 | 锁 | 锁 | 锁定 | 对应步骤 |

## 5. 干预选择题：全选流程（②与聊天集成）

标准流程（①③④，浮于 3D 之上）：

```
choice → 全锁+解锁鼠标 → 面板淡入：标题(题干)+选项卡(稿_列表_默认/选中)
 → 点选任一项 → 该卡下方展开解释正文(0.2s) → 转"已记录"态不可再点
 → 剩余项依次选完 → "记入焦虑记录本"主按钮点亮 → 点击收档 → 淡出回剧情
```

**②（S78，浮于手机聊天 UI 上）差异**：收档后**把玩家第一个选中的选项文本作为林溪的消息气泡发进聊天**（补完她那句"实在不行我陪你练，而且——"），停 0.8s 再执行 `cam:phone_out` 回切徐夏——玩家"替林溪说的话"真的出现在聊天里。选择顺序记录进 PlayerPrefs（`SaveSystem` 扩展 `ch1.choice2=顺序`），供二期联动概览页。

**林溪无实体**：手机 UI 方案下完全不需要林溪 3D 实例与镜头切换。

## 7. 文本组件决策：换回 uGUI Text（用户问"会不会模糊"）

- **不模糊**。Unity 动态字体按 Text 组件请求的字号实时烘焙字形，只要：①字号直接设目标值（name 36 / neirong 28），②不用 transform Scale 放大文本，③Canvas 按 1920×1080 参照分辨率——渲染即清晰。主菜单全部 uGUI Text+中文_Deng 已验证。
- TMP 的优势是 SDF 任意缩放皆清晰，本项目无此需求；且统一 uGUI 后与主菜单同管线、免维护 TMP 字体资产。
- `Chapter1StoryBuilder` 负责把 name/neirong 的 TMP 组件替换为 uGUI Text（中文_Deng、目标字号、深底白字）。
