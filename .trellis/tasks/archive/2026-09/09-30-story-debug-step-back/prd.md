# 剧情调试：回退到上一句

## Goal

给剧情系统加一个**仅编辑器可用**的调试能力：按一个键就能回到上一句台词并重播，
方便快速重看文字 / 重听语音，不用从头跑章节。

## Requirements

- 触发按键默认 `Backspace`（Inspector 的「调试（仅编辑器）」分组可改）。
- 整段功能包在 `#if UNITY_EDITOR` 内，正式构建不编译进来。
- 只在"正停在一句话上"时生效：`State.Typing` / `Gap` / `NarFree`；其它状态（选择题、
  交互段、走位、黑屏、结束卡）按了无反应。
- 回退目标 = **当前连续文本段内的上一句**（`nar` / `dlg` / `mon`）：
  - 重播打字机、名牌/遮罩语态、该句语音；
  - 往回扫描遇到非文本步骤（`interact` / `walk` / `fade` / `enter` / `leave` / `choice` / `card`）
    即停在段首，不允许退过去（不重放世界状态、不重新武装交互点）。
- 微信段（`s` 含「（微信）/（通知）」）：回退时把手机上多余的气泡**精确摘掉**
  （`PhoneChatUI.RemoveLast`，按记录高度回收），不跨手机聊天流被清空的点
  （换联系人 / 重新亮屏），保证手机内容 == 正常玩到该句时的状态。

## Acceptance Criteria

- [ ] 编辑器编译通过（脚本无语法/引用错误）。
- [ ] 连续对话里连按回退键可逐句往回，退到本段首句时给出提示并停住。
- [ ] 微信段回退后：气泡数量与"正常玩到上一句"一致、联系人不串。
- [ ] 非文本状态按回退键无任何副作用。
- [ ] `#if UNITY_EDITOR` 之外无该功能残留（正式构建不含）。
- [ ] 不改 json、不改存档语义、不改变正常推进路径的行为。

## Notes

- 轻量任务（PRD-only）。改动集中于 `StoryRunner.cs` / `PhoneChatUI.cs` 两个运行时脚本。
- 验收里"编辑器编译 + Play 实测"依赖 Unity 编辑器；本次环境未运行 Unity，
  只能做静态检查，需用户在编辑器里刷新编译后试一把（见 implement 记录/journal）。
