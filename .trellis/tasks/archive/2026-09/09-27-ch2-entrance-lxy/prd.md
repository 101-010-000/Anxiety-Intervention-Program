# 第2章陆宣雨入场演出：门口虚影渐显走近触发对话

## Goal

第二章的陆宣雨不再是"本来就在宿舍站着"：开场她**不在宿舍**；剧情进行到
「她抬头看了看宿舍门，刚好看到宿舍长端着水杯走进来」时，陆宣雨**从宿舍南门出现**——
以**虚影形态缓缓显形（从虚慢慢变实）**并同时**走向主角**，到达主角身旁后"落定"为
真实形象，随后接上她与徐夏的对话（现有 json 台词不动）。

演出定位：把"别人主动来找徐夏"的进场做成一段有过程感的演出，而不是凭空站着说话。

## 现状（2026-09-27 核验）

- 陆宣雨实例在 `Loc_宿舍/第二章角色/` 下，静态摆放（挂 `PC_待机_女.controller`，播待机）。
- 宿舍南墙有门框：`Loc_宿舍/Shell_墙/南_门框墙_2`，本地坐标约 (2, 0, -6)；第2章主角起点在书桌旁 (0, 0, -0.5)——门口到书桌约 6m。
- 行走动画 FBX 现成：`03_动作_Animation/动画/行走.fbx`（女版）、`Walk.fbx`；Animators 里有 `PC_待机_女.controller` 可作底。
- 角色主着色器 = ShaderGraph_CharacterLit（**不透明、9 角色共享**——不能动）。
- 描边 = OutlineFeature 按层画实心反向外壳（overrideMaterial 不透明黑壳）——半透明阶段会穿帮。
- 第2章 json（78 步）已上线可用；`enter` 步骤模式可照抄 `fade`（StoryRunner 协程）。

## Requirements

### R1 入场时序（第2章 json 只插 1 步，台词零改动）
- 第2章开场（Begin 后）：陆宣雨 GameObject 禁用（她不在宿舍）。
- 微信段结束、旁白「她抬头看了看宿舍门……」之后，原 `dlg 陆宣雨 怎么了？...` 之前，插入
  一步 `enter`（新步骤类型）驱动整段入场演出；演出完自动进入原对话流程。
- 演出时长目标 3~4 秒（门口→书桌 6m，缓速走近）；期间玩家全锁（同 fade 状态）。

### R2 虚影渐显（方案 A，★ 不动 ShaderGraph / 不动现有材质资产）
- 激活瞬间：她所有 SkinnedMeshRenderer 的材质**临时替换**为新写的半透明"虚影材质"
  （统一淡色，如淡青白；新 shader `CharacterGhost`，简单 unlit/lit 透明，~40 行 HLSL）。
- 显形曲线：alpha 0 → ~0.75 随位移进度渐升（越走越清晰）。
- 到达主角旁：**换回原材质**（真实配色"落定"成真人）→ 恢复描边/碰撞 → 触发对话。
- 临时替换只发生在运行时（MaterialPropertyBlock 或 renderer.materials 数组换回），场景资产零污染。

### R3 走近移动（★ 落点动态 = 玩家面前，不写死坐标）
- 路线：南门内 (≈2, 0, -5.5) → **玩家面前**：enter 开始时快照玩家位置 P，
  终点 = P + (门口→P 方向单位向量) × 1.3m（从她的来向走到玩家跟前停下）；
  到位后面向玩家。玩家此刻必在手机交互点 2.2m 半径内（interact 收敛 + 对话锁移动），
  但位置不精确——所以**不能用固定锚点当落点**（用户 2026-09-27 指出）。
- `to` 字段为可选覆盖：缺省 = 玩家面前 1.3m；显式给锚点名时才走固定落点（特殊演出预留）。
- 位移：协程插值 + 面朝移动方向；同时播行走动画（给陆宣雨挂"待机+行走"controller，
  由 Editor 工具生成/接线；到位后切回待机）。
- 速度均匀偏缓（演出感），到达后平滑停住；enter 期间玩家全锁，无"追人"问题。

### R4 穿帮防护（两个预判坑）
- 描边：入场期间她不参与描边（临时改 Layer 或禁用方式由实现定），落定后恢复 `Outline` 层。
- 碰撞：入场期间禁用她的 CapsuleCollider（半透明幽灵不该挡人/被撞），落定后恢复。

### R5 机制通用化
- `enter` 步骤参数化：谁入场（场景节点名）、从哪（起点锚点）、到哪（终点锚点）、可选速度/时长。
- 第4章林溪「抱着复习资料走进宿舍」同构，后续加一行 json + 一组锚点即可复用（本次不实施，只保证不写死）。
- 第1章及其它章零影响（没有 enter 步骤就不触发任何逻辑）；第1章自检回归必须通过。

### R6 工具与回归
- Editor 工具扩展（幂等菜单）：建入场锚点（门口起点/书桌旁终点）、给陆宣雨生成/挂
  "待机+行走" controller、把 enter 所需的引用接到第2章 runner（或全局注册表）。
- 第2章自检通过（enter 步骤在自检里可被 DebugAdvance 推进）；第1章自检回归通过。

## 非目标
- 不做真·原材质透明渐显（改 ShaderGraph 加 _Fade）——将来可选增强，本次不做。
- 不做第4章林溪入场（只留通用机制）。
- 不做端水杯道具/手部动作；不做她的转向看镜头等高级演出。
- 不改对话 UI / 不新建任何 UI。

## Acceptance Criteria

- [ ] 微信段后旁白接 enter：陆宣雨从南门以半透明虚影出现，边走边变清晰，约 3~4 秒**走到玩家面前 1.3m 处**（无论玩家站在交互半径内哪个位置），落定为真实配色并面向主角，随后自动开始她的第一句台词。
