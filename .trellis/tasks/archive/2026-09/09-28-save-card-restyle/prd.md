# 存读档卡片美化：去白底/圆角/文字不压图

## Goal
修复存读档页「有档」卡片的观感问题（2026-09-28 用户试玩截图反馈）：
1. 白色实底外露（`实底`节点 = 稿_卡片_1 白卡），截图浮在白底上；
2. 截图直角、无裁切（16:9 原图硬塞 316×140 框）；
3. 章节标题（y=-52）与缩略图（下缘 -48）重叠；
4. 截图内容本身是「干预选择题面板完整显示」那一刻的画面（StoryRunner.CaptureChoiceThumb），是 UI 不是游戏场景。

**定稿方案（用户 2026-09-28 三选一拍板）**：章节场景定妆照——不用运行时截图。每章预渲染一张干净游戏场景图（复用 ScenePostFx 后期预览机位、开后期、无 UI 入镜），圆角 + 底部信息压暗带直接烘进 PNG；存档卡整卡铺图，章名/时间压在暗带上。

## Requirements
- R1 定妆照 5 张：ch1=教室 / ch2=宿舍 / ch3=办公室（场景键 `Loc_办公室`）/ ch4=图书馆 / ch5=宿舍（与 ch2 同屋，机位水平偏转约 180° 区分）。720×400（卡片 1.8:1 的 2 倍），圆角 alpha + 底部渐变压暗带烘进图。
- R2 有档卡：整卡铺定妆照；白色实底隐藏；章名（白字）/时间（浅灰字）落在暗带内，与图零重叠。
- R3 空档卡：保持现状（虚线空框 +「空存档」）。
- R4 选中线框（稿_卡片_2）保留，且渲染在定妆照**之上**（现状层级是图盖住线框，一并修）。
- R5 槽位网格/卡片尺寸不动（360×200，3 列 × 2 行，间距 384×230）；**只做槽位子树补丁，不重建主界面场景**，其他页手调零影响。
- R6 StoryRunner 现有抓屏/自动存档逻辑不删不改（SaveData.thumbnail 照写）；UI 显示优先定妆照，缺图时回退旧截图路径（兼容老档）。
- R7 工具幂等，支持触发器 `Assets/_savecard_trigger.txt`；报告/预览落 `assets/_报告/`。
