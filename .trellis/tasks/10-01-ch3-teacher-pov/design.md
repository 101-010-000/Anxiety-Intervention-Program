# Design：第三章办公室段改为李老师视角演出

## 机制映射（全部复用现有引擎，仅加 1 个小步骤类型）

| 演出需要 | 用什么 | 现状 |
|---|---|---|
| 镜头切到老师背后、跟随移动 | `{"t":"cut","who":"李老师_走廊"}` / CutawayCamera（身后 2.6m LookAt 头部，持续跟随） | 已有（9-30 用于食堂段） |
| 老师沿走廊走位、先转身再走 | `{"t":"leave","who":"李老师_走廊","to":"第3章_老师到门口","via":[…],"hide":true}`（NpcEntrance.RunPath；写 Speed 驱动李老师_Walk） | 已有 |
| 黑屏换片场（走廊 29m ↔ 办公室 155m，中间是虚空，必须借黑屏） | `{"t":"fade","to":"第3章_办公室内"}`（黑屏淡入→传送玩家→淡出） | 已有 |
| 老师进屋走到沙发前 | 黑屏后 `cut who=李老师_可动` + `leave to=第3章_老师站位` | 已有 |
| 徐夏"已经在办公室中"（坐姿可见 + 不出现两个徐夏） | **新步骤 `stage`**：亮/收 `徐夏_办公室坐姿` + 藏/显玩家自身模型 | **新增** |
| 切回玩家 + 起身 | `{"t":"cut"}`（Restore + FPC enable）+ stage 的反向操作 + 原地起身面向门口 | cut 已有；起身是 stage 的一部分 |

## 关键决策

1. **两个李老师实例（走廊 + 办公室），不做 fade 搬运 NPC**。项目惯例就是按 Loc 摆实例（林溪_宿舍 vs 林溪_可动）；黑屏切实例 = 电影切镜头，零引擎改动。走廊实例走到门口 `hide:true`——到位即隐藏，同一帧进入 fade 的黑屏淡入，"凭空消失"被黑屏盖住；这样玩家出门回到走廊尾（29.32,-0.93，与门口同点）时不会撞见第二个老师。
2. **坐姿徐夏是"舞台道具"而非真坐下**：老师视角段玩家输入全锁、镜头在老师身上，玩家胶囊在哪无关紧要；让 SitSpot 那套"记录原站位/起身回传"参与进来反而会踩"起身回传到食堂"的坑（AGENTS 已记）。所以：fade 落地把玩家传到 `第3章_办公室内`（站姿，藏自身模型），亮出 `徐夏_办公室坐姿`；切回时反向，玩家在 `第3章_办公室起身` 锚点**原地起身**（模型恢复可见），不经过 SitSpot、不记录/回传原站位。坐姿模型由用户手摆，位置=沙发，坐姿姿态靠 SitHere（Start 置 Sitting）+ `徐夏_第三人称` 控制器的 Sit 状态。
3. **新步骤 `stage`**（命名可定 `stage`）：`{"t":"stage","show":["徐夏_办公室坐姿"],"hidePlayer":true}` 与 `{"t":"stage","hide":["徐夏_办公室坐姿"],"showPlayer":true,"standAt":"第3章_办公室起身"}`。实现要点：
   - show/hide 列表按名解析场景物体（同 FindFadeAnchor 风格，找不到警告一次）；
   - 藏玩家 = `FirstPersonController.SetStandingModelVisible(false)`（连描边外壳一起没，复用坐姿换模型的既有做法）；恢复 = true；
   - `standAt` 非空时把玩家传到该锚点 + yaw 朝向 + `ResetCameraNow()`（照抄 fade 的关 CC→挪→开 CC 三步）；
   - `SilentApply`（续播快进）同步执行同一套操作，保证续播后世界状态一致；
   - 章末 `ToDone` 兜底：showPlayer=true（防中间退出剧情后玩家模型一直隐形）。
4. **语音零合成**：删 5 步（71–75 全非语音）、插 5 步左右（leave/fade/stage/cut/stage… 全非语音）——实施时把插入数凑成与删除数相等，台词步号整体零位移，manifest 不用动；万一凑不平，跑 `voice_shift_steps.py`（只改键名/文件名，不合成）。改动后必跑 VoiceLineDiag 对账。
5. **json 步骤草案**（65 起）：
   ```
   65 cut who=李老师_走廊                     （改：原 who=李老师_可动）
   66-70 dlg×2 + nar×3                        （原样保留）
   71 leave who=李老师_走廊 to=第3章_老师到门口 via=[第3章_老师路线_1,…] hide=true   （新）
   72 fade  to=第3章_办公室内                  （新，原 75 的落点）
   73 stage show=[徐夏_办公室坐姿] hidePlayer  （新）
   74 cut   who=李老师_可动                    （新；黑屏后接上，走廊→办公室无残帧问题：
                                                fade 协程完整跑完才 Next，切实例发生在亮屏后一瞬，
                                                观感即"切镜头"）
   75 leave who=李老师_可动 to=第3章_老师站位   （新；锚点 yaw=面向沙发）
   76…119 办公室谈话 + 两道选择题              （原样保留）
   120 cut                                     （新：切回玩家）
   121 stage hide=[徐夏_办公室坐姿] showPlayer standAt=第3章_办公室起身   （新）
   122… interact 第3章_办公室出口 + fade 第3章_走廊尾 + 结尾   （原 120–141 原样）
   ```
   删 5 插 5（71–75 → 新 71–75；120/121 两步使尾部 +2 → 语音键尾部跑一次 shift；实施时先算精确差值再定凑平方案）。
6. **走廊跟拍蹭墙风险**：CutawayCamera 吊臂 2.6m，走廊净宽有限。先实测；若穿墙，给 cut 步骤加可选 `dist`（CutawayCamera.Show 已有 camH/lookH 覆盖参数可扩展），本段用更近机位（如 1.8m）。
7. **FindCharacterTransform 按名查找**：走廊实例必须唯一名（已改名 `李老师_走廊` ✓）。办公室实例保持 `李老师_可动`（全场景唯一）。
8. **交接线工具**：新增 `Assets/Editor/Ch3TeacherPovSetup.cs`（菜单 `Tools/干预项目/第三章老师视角/`，幂等）：补建缺失锚点（`第3章_老师到门口`/`第3章_老师路线_N`/`第3章_老师站位`/`第3章_办公室起身`，已存在绝不改位置）+ 校验走廊/办公室实例、坐姿模型、stage 引用，报告 `assets/_报告/_第三章老师视角.txt`。路线点摆位留给用户手拖。

## 兼容与回滚

- 改动集中在：第3章.json、StoryRunner.cs（stage 步骤 + ToDone 兜底）、CutawayCamera.cs（可选 dist）、新 Editor 工具、（语音键位移脚本跑一次）。
- 回滚 = 还原 json + 删 stage 分支；场景侧锚点/实例保留无害。
- 其他章零影响：stage 步骤只有第3章用；走廊第三章容器按章显隐既有逻辑覆盖。
