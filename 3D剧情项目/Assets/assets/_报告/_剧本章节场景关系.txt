========================================================================
剧本章节 × 场景关系 × 角色一览（整理自 项目文档/剧本.docx，共 5 章）
========================================================================
场景名以 Game.unity 的 6 个地点（SceneBuilder.cs 的 Loc_*）为准：
Loc_教室 / Loc_走廊 / Loc_宿舍 / Loc_食堂 / Loc_办公室(咨询) / Loc_图书馆

【全局结构】
每章 = 一个焦虑主题，剧情节奏固定为：
  焦虑触发 → ①自我视角焦虑记录 → 寻求支持（微信或当面）
  → ②帮"安慰者"补充一句鼓励 → ③新认知记录（旁观者/老师/环境视角）
  → ④未来自我视角创作（1年后的自己）→ 情绪释然收尾
①~④全是弹窗/面板交互，不切场景。主角徐夏贯穿 1–5 章。

------------------------------------------------------------------------
第一章 小组作业汇报焦虑（社交表现焦虑）
------------------------------------------------------------------------
剧情线：专业课下课，组长把汇报任务定给徐夏 → 她慌乱、灾难化想象
→ ①自我焦虑记录 → 在座位上微信找林溪倾诉（剧本此处整体"视角切换至林溪"）
→ ②帮林溪补一句鼓励 → 收拾书包走出教室，门口撞到张知远，被开导
→ ③旁观者视角记录（张知远：放大失误、忽略信任/自身优势）
→ 想象 1 年后的自己 → ④未来自我创作 → 夕阳下释然。
时间：傍晚（收尾有"夕阳洒在她身上"）。

场景关系与动线：
  教室（主场景：第三排座位，组长对话、微信聊天都在这里）
   → 教室门口（撞张知远）
   → 走廊（目送张知远、远眺教学楼收尾）
  教室→走廊相通（走廊本就是"教室外走廊"）。

角色：
  实体：徐夏、组长、张知远
  微信/切视角：林溪（本章有一段真的"视角切换至林溪"）
  ⚠ 剧本笔误：交互③写"在李同学看来"，上下文应为张同学（张知远）。

------------------------------------------------------------------------
第二章 拒绝邀约焦虑（怕被孤立）
------------------------------------------------------------------------
剧情线：宿舍书桌赶完作业 → 同班李同学微信约火锅+电影 → 两难
（怕拒绝后被孤立 / 怕去了融不进）→ ①自我焦虑记录 → 微信问林溪
→ ②帮林溪补鼓励 → 宿舍长陆宣雨端水杯进来，当面开导
→ ③旁观者视角记录（放大拒绝后果、忽略自身感受）
→ 想象未来自己 → ④未来自我创作 → 婉拒李同学，对方爽快理解
→ 爬上床安心休息。
时间：下午三四点。

场景关系与动线：
  全章唯一实体场景 = 宿舍（书桌 → 椅子 → 床），不出门。
  所有对外联系都是微信（林溪、李同学）。

角色：
  实体：徐夏、陆宣雨（宿舍长）
  仅微信：林溪、李同学（李同学不在 9 人角色表内，无需 3D 模型）

------------------------------------------------------------------------
第三章 考研/就业迷茫（未来方向焦虑）
------------------------------------------------------------------------
剧情线：宿舍躺了一小时缓过来 → 和林溪约饭 → 食堂靠窗位边吃边聊，
林溪问考研还是就业 → 徐夏焦虑上头 → ①自我焦虑记录 →
同班王含拼桌，两人规划清晰，徐夏自愧不如 → 时间跳到下午：
辅导员按安排逐个约谈学生，轮到徐夏 → 咨询办公室里（徐夏已在沙发上
翻资料等老师）李老师温和开导 → ②帮李老师补鼓励 →
③老师视角记录（不自觉攀比忽略优势、把迷茫当失败）→
走出办公室路上想象未来 → ④未来自我创作 → "既然未知，就去了解好了"。
时间：临近饭点的午餐 + 当天下午。

场景关系与动线：
  宿舍（起点，简短）→ 食堂（主场景1：三人同桌）→ 咨询办公室（主场景2）
  → 办公室外/走廊（收尾独白）
  宿舍→食堂是"约饭"；食堂→办公室是时间跳转（不在镜头内）。

角色：
  实体：徐夏、林溪、王含、李老师
  本章无微信-only 角色，是唯一"4 个实体角色同章"的章节。

------------------------------------------------------------------------
第四章 考试周 + 论程论文双重压力
------------------------------------------------------------------------
剧情线：日常恢复秩序 → 这天徐夏刚从图书馆回到宿舍坐下 →
班群通知：下周三期末模拟考 + 下周五论文截止 → 慌乱 →
①自我焦虑记录 → 宿舍太吵无法专注、怕麻烦别人不敢问 →
微信求助高一届学姐，学姐给方法（优先级清单、论文分三步）
→ ②帮学姐补鼓励 → 林溪抱着复习资料来宿舍，约去图书馆 →
两人并肩去图书馆 → 靠窗位一起复习，安静氛围让徐夏平静 →
③环境带来的新认知（本章第③步是"环境视角"而非旁观者：
放大困难自己吓自己 / 忽略身边陪伴）→ 想象未来 →
④未来自我创作 → 坚定开始按计划复习。
时间：白天。

场景关系与动线：
  图书馆（章前路过，仅提及）→ 宿舍（焦虑爆发点：班群通知、舍友嘈杂）
  → 图书馆（解决场景：安静、靠窗、有人陪）→ 留在图书馆收尾。
  本章核心是"宿舍(吵/焦虑) vs 图书馆(静/治愈)"的往返对比。
  舍友在宿舍作背景（怨声载道聊复习，未具名）。

角色：
  实体：徐夏、林溪、（未具名舍友×背景）
  仅微信：学姐（不在 9 人角色表内，无需 3D 模型）

第五章 宿舍人际关系误会（敏感内耗）
------------------------------------------------------------------------
剧情线：期末考完回宿舍 → 察觉氛围不对 → 回忆考试前在宿舍背书时，
一舍友叹气摔门离开的细节 → 自我怀疑滚雪球 → ①自我焦虑记录 →
几小时小心翼翼、不敢出声 → "落荒而逃"去图书馆 → 傍晚回宿舍，
舍友们欲言又止（徐夏视角看是冷淡）→ 正想微信问林溪要不要一起吃饭，
宿舍长陆宣雨主动邀约 → 徐夏下意识婉拒后情绪爆发、说出误会 →
陆宣雨大笑澄清（出门关门是要打电话怕吵她背书；停聊是在聊放假去哪玩）
→ 舍友A/B也澄清（怕打扰她复习才少说话）→ ②帮陆宣雨补鼓励 →
③舍友们旁观视角记录（放大细节当恶意 / 疏远忽略了沟通）→
误会解开，徐夏请客 → 全员一起去食堂 → 路上欢声笑语，
想象未来 → ④未来自我创作 → 释然。
时间：期末结束当天，傍晚收尾（夕阳）。

场景关系与动线：
  考场（仅提及，无对应 Loc）→ 宿舍（主场景1：压抑）
  → 图书馆（躲避）→ 宿舍（主场景2：傍晚对峙与和解）
  → 食堂（收尾：全员同行吃饭，呼应第 3 章食堂）。
  宿舍↔图书馆是"逃离-返回"；宿舍→食堂是"和解同行"。

角色：
  实体：徐夏、陆宣雨、舍友A、舍友B（宿舍 4 人全员到齐的唯一章节）
  提及：林溪（想约饭未遂，被陆宣雨打断）

对接项目的实现要点
------------------------------------------------------------------------
1. 6 个 Loc 完全够用，无缺场景；考场（第5章开头）可跳过或复用教室。
2. 第 2、4 章大量微信聊天 → 需要手机 UI 面板；主角 Animator 已有
   Phone(Bool)/TakePhone(Trigger) 状态可直接衔接。
3. 第 1 章有真正的"视角切换至林溪"段落 → 需要镜头/控制对象切换。
4. 每章 4 个干预交互点全是面板，不切场景；第 4 章第③步是"环境视角"
   （其余章为旁观者/老师视角），UI 文案要区分。
5. 各章时间/氛围：1章傍晚、2章午后、3章午市+下午、4章白天、5章傍晚——
   可配合 ScenePostFx 每地点氛围 Volume 做章节滤镜。
6. 剧本笔误一处：第 1 章交互③"在李同学看来"应为张同学（张知远）。
